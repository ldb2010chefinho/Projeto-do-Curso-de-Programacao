Votação Mobile-first

    
Qual é mobile-first?

    

      

        A
        
++

        
Começa no celular e adiciona estilos para telas maiores usando min-width.

      

      

        B
        
−−

        
Começa no computador e remove coisas para telas menores usando max-width.

      

    

    
A. Mobile-first é começar pela tela menor, só com o essencial, e ir adicionando conforme a tela aumenta. Isso obriga a decidir o que é mais importante.

  







  

    
Não confundir os dois “mobile-first”

    

      
Quem faz: você
Mobile-first CSS
Uma forma de escrever CSS começando pela tela pequena.
@media (min-width: 768px) { … }

      
≠

      
Quem faz: o Google
Indexação mobile-first
O Google usa a versão mobile do site para fazer a indexação e o ranking.

Conserto 3 srcset e sizes · DevTools › Network

    

      


<img
  src="burger-800.jpg"
  srcset="burger-400.jpg 400w, burger-800.jpg 800w, burger-1600.jpg 1600w"
  sizes="100vw"
  alt="Hambúrguer artesanal da Lanchonete Pixel">

        
srcset oferece o mesmo desenho em tamanhos diferentes, e o navegador escolhe o arquivo adequado. sizes="100vw" diz que a imagem ocupa a largura da tela.

        
E o <picture> vai além: troca a foto inteira conforme a tela (close no celular, foto larga no computador).
