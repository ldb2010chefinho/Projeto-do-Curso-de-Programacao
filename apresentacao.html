Votação Mobile-first

    
Qual é mobile-first?

    

      

        A
        
++

        
Começa no celular e adiciona estilos para telas maiores usando min-width.

      

      

        B
        
−−

        
Começa no computador e remove coisas para telas menores usando max-width.

      

    

    
A. Mobile-first é começar pela tela menor, só com o essencial, e ir adicionando conforme a tela aumenta. Isso obriga a decidir o que é mais importante.

  







  

    
Não confundir os dois “mobile-first”

    

      
Quem faz: você
Mobile-first CSS
Uma forma de escrever CSS começando pela tela pequena.
@media (min-width: 768px) { … }

      
≠

      
Quem faz: o Google
Indexação mobile-first
O Google usa a versão mobile do site para fazer a indexação e o ranking.

Perguntas

    

      
Por que usaram o dado mundial e não o do Brasil?
[colar a resposta do roteiro]

      
Design responsivo e design adaptativo são a mesma coisa?
[colar a resposta do roteiro]

      
Sem a meta viewport o CSS responsivo funciona?
Sem ela, o navegador do celular finge ser uma tela de computador de ~980px e encolhe a página. A meta viewport faz ele usar a largura real da tela.

      
Quando usar Flexbox e quando usar Grid?
Flexbox: uma dimensão (linha ou coluna), como o menu. Grid: duas dimensões (linhas e colunas), como a página inteira, a grade de cards e o cardápio.

      
Quais breakpoints usar?
Onde o conteúdo começa a ficar ruim, e não “a largura do iPhone”.

      
Mobile-first CSS é a mesma coisa que a indexação mobile-first do Google?
Não. Mobile-first CSS é escrever o CSS começando pela tela pequena. Indexação mobile-first é o Google usar a versão mobile do site para indexar e ranquear.

      
rem e em: qual a diferença?
em é relativa à fonte do próprio elemento; rem, à fonte da raiz (html).

      
Container queries funcionam em todo navegador?
[colar a resposta do roteiro]

      
Vale a pena aprender CSS se existe Bootstrap e Tailwind?
Por baixo dos frameworks estão Flexbox, Grid e media queries. Quem entende o CSS entende qualquer framework.

      
O DevTools substitui o teste no celular real?
Não. O simulador não reproduz o toque, o desempenho do aparelho nem a tela no sol.
